# אִיבַּעְיָא לְהוּ

אפליקציית שאלות ותשובות בעברית (iOS, Android ו־Web), בנויה ב־Expo ו־Expo Router.
אפשר לחפש שאלה בכתב, לעיין לפי נושאים, לקרוא תשובה עם "מתאים לך אם / פחות מתאים אם",
לשמור תשובות, לשלוח אותן הלאה ולשמוע הקראה. הממשק כולו מימין לשמאל, עם ערכות צבע בהירה וכהה.

## הרצה

```bash
npm install
npx expo start
```

בדיקות לפני שמירה: `npx tsc --noEmit` ו־`npx expo lint`.

## הנתונים

הנתונים נבנים מהמאגר הערוך בעזרת:

```bash
python3 scripts/build-data.py
```

הסקריפט כותב שני קבצים:

- `assets/data/qa.json` – המאגר המלא. **לא נשמר ב־git** (מופיע ב־`.gitignore`).
- `assets/data/qa.sample.json` – מדגם קטן שנשמר במאגר לצורכי פיתוח.

**פרטיות:** המאגר המקורי כולל פרטים מזהים. הסקריפט מעתיק רק שדות ציבוריים
(`id`, `question`, `answer`, `topics`, `applies_when`, `not_when`, `faith`, `source_kind`)
ולא שום שדה אחר. אין להוסיף שדות לרשימה הזו.

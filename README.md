# אִיבַּעְיָא לְהוּ

אפליקציית שאלות ותשובות בעברית (iOS, Android ו־Web), בנויה ב־Expo ו־Expo Router.
אפשר לחפש שאלה בכתב, לעיין לפי נושאים, לקרוא תשובה עם "מתאים לך אם / פחות מתאים אם",
לשמור תשובות, לשלוח אותן הלאה ולשמוע הקראה. הממשק כולו מימין לשמאל, עם ערכות צבע בהירה וכהה.

## הרצה

```bash
npm install
npx expo start
```

בדיקות לפני שמירה: `npx tsc --noEmit` ו־`npx expo lint`.

## שאלות בלי תשובה

"לא מצאתם תשובה?" שולח רק את נוסח השאלה, את זמן הכתיבה ואת גרסת האפליקציה. לא נשלחים מזהה מכשיר, פרטים אישיים
או היסטוריית חיפוש. הכתובת נקבעת במשתנה הסביבה `EXPO_PUBLIC_QUESTIONS_ENDPOINT`, למשל בקובץ `.env`.
בלי כתובת, או בלי חיבור, השאלה נשמרת במכשיר ונשלחת בפעם הבאה שיש חיבור. אפשר לשלוח עד 5 שאלות ביום, ועד 500 תווים לשאלה.
צד השרת הוא Google Apps Script שכותב לגיליון: `server/google-apps-script/Code.gs`. הוראות ההגדרה:
`server/google-apps-script/SETUP.he.md`.

## הנתונים

הנתונים נבנים מהמאגר הערוך בעזרת:

```bash
python3 scripts/build-data.py
```

הסקריפט כותב שני קבצים:

- `assets/data/qa.json` – המאגר המלא. **לא נשמר ב־git** (מופיע ב־`.gitignore`).
- `assets/data/qa.sample.json` – מדגם קטן שנשמר במאגר לצורכי פיתוח.
- `assets/data/similar.json` – "לא רק אתם": לכל תשובה רק טווח גס (כמה / עשרות / מאות פעמים) של שאלות כמעט זהות
  מתוך כל השאלות שחולצו (`prod/raw`, כל סטטוס), לפי מספר הקלטות שונות. אין מספרים מדויקים, ואין טווח לפחות משלוש.
  הדמיון: מילים מנורמלות (בלי ניקוד, אותיות סופיות, תחיליות וסיומות נפוצות ומילות עצירה) וזוגות מילים,
  TF-IDF ודמיון קוסינוס ‏0.45 לפחות. הסף נבחר על מדגמי זוגות (`review/not-alone-calibration.md`).

**פרטיות:** המאגר המקורי כולל פרטים מזהים. הסקריפט מעתיק רק שדות ציבוריים
(`id`, `question`, `answer`, `topics`, `applies_when`, `not_when`, `faith`, `source_kind`, `sensitive`)
ולא שום שדה אחר. אין להוסיף שדות לרשימה הזו.

`sensitive` הוא בוליאני בלבד: אמת כשסוג הרגישות של הרשומה הוא רפואי, נפשי, סיכון לפגיעה או משפטי,
או כשיש לה `safety_flag`. הקטגוריה עצמה לא נכתבת. רשומה רגישה לא מציעה שליחה ("שלחו בעדינות"),
ולא מופיעה בהתראות היומיות, ב"קשה לי עכשיו" או בתשובות לעונה.
